# Documentation index

This index classifies the checked-in documentation without rewriting measured evidence.
Dates and “next step” instructions in historical records describe that observation, not
permission to execute an operation today. Follow current guidance and inspect effective
configuration before acting. New acceptance records are historical evidence by default.

The [canonical specification](../SOFTWARE-FACTORY-PLAN.md) remains authoritative;
[discovery measurements](discovery/) win where they contradict its assumptions.
[AGENTS.md](../AGENTS.md) supplies repository boundaries. Neither is archived or rewritten.
